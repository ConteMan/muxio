# ADR-003：先实现内置连接器

- 状态：已接受
- 日期：2026-08-10

## 背景

连接器协议在没有真实实现和故障证据前容易冻结错误抽象。外部 ABI、SDK 或进程协议还会立即增加兼容性和安全维护成本。

## 决策

首期连接器作为 Go 内部接口实现。用 file 与 RSS/Atom 验证配置、checkpoint、候选记录、取消和错误语义；核心统一负责调度、重试、事务、去重和运行状态。

## 后果

- 首期不承诺外部连接器兼容性。
- 连接器接口可以随两个真实实现共同调整，但必须同步 Spec。
- 只有出现第三方扩展需求并且接口稳定后，才评估 SDK 或独立进程协议。
