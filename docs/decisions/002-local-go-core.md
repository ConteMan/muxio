# ADR-002：采用本地 Go 核心

- 状态：已接受
- 日期：2026-08-10

## 背景

Muxio 需要长期在个人设备稳定运行，支持本机和网络来源，并尽量降低安装、运维和数据迁移成本。

## 决策

核心采用 Go 单二进制，CLI、HTTP API、调度与采集同进程；SQLite 是首期唯一数据库。`muxio serve` 是唯一长期写入者，HTTP 默认仅监听 loopback。

## 后果

- 部署和备份保持简单，可跨平台发布单文件程序。
- 连接器故障必须通过超时、取消和边界隔离控制，不能依赖服务拆分兜底。
- 不引入消息队列、外部数据库或无实际容量证据的分布式组件。
- 未来远程访问必须先补认证和威胁模型，而不是开放监听地址。
