# ADR-001：采用轻量 Monorepo

- 状态：已接受
- 日期：2026-08-10

## 背景

Muxio 核心 API 与早期 Web 会频繁共同演进。现在拆仓会增加契约版本、跨仓评审和原子变更成本，但把未来所有客户端提前建入同仓也会制造无效维护面。

## 决策

Go 核心和独立 Web 放在 `muxio` 同一仓库。两者独立构建、运行、测试、版本和发布，唯一共享合同是 `api/openapi.yaml`。浏览器、桌面和移动项目在真实启动时再决定加入或拆仓。

## 后果

- API、核心和 Web 可以在一个 PR 原子演进。
- CI 可按目录拆分，但统一由根门禁收口。
- Go 构建不得依赖 Web 工具链，Web 不得访问核心内部实现。
- 当权限、团队、发布节奏或仓库体积形成实际负担时，可将客户端拆仓。
