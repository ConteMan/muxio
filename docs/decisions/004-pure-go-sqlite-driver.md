# ADR-004：采用纯 Go SQLite 驱动

- 状态：已接受
- 日期：2026-08-10

## 背景

ADR-002 确定 SQLite 是首期唯一数据库，并承诺跨平台发布单文件程序。Spec 002 需要引入 Muxio 的第一个外部直接依赖：SQLite 驱动。

候选是 `mattn/go-sqlite3` 与 `modernc.org/sqlite`。前者是 cgo 绑定，成熟且性能最好；后者是 SQLite C 源码的自动翻译产物，纯 Go 实现。

驱动选型难以事后逆转：它决定构建方式、交叉编译成本和发布流程，且一旦有数据落盘，更换驱动要重新验证全部持久化行为。

## 决策

采用 `modernc.org/sqlite`。

## 后果

- 构建不需要 cgo。M4 的 macOS、Linux、Windows 交叉编译不必为每个目标平台准备 C 工具链，`CGO_ENABLED=0` 即可完成全部发布产物。
- 该驱动包含 FTS5，可支撑 M1 第 3 片的全文搜索，不需要再次更换驱动或维护构建标签。
- 测试与 CI 保持单一 `go test`，不引入平台相关的编译分支。
- 代价是写入吞吐低于 cgo 绑定。Muxio 是单用户本地工具，写入来自个人规模的采集，该差距不构成约束；若未来出现真实性能证据，需新增 ADR 取代本决策。
- 依赖体积较大且更新频繁，由 Dependabot 跟踪；升级必须通过 `selftest` 的完整门禁，尤其是幂等与并发写入测试。
