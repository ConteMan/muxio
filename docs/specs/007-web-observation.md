# Spec 007：前端工具链与观察面板

- 状态：已实现
- 关联：Roadmap M3 第 1 片、ADR-001、ADR-007、Spec 005

## 问题

`/api/v1` 已经提供了运行历史、运行事件和配置，但维护者仍然只能通过终端查看。这正是重排里程碑要解决的事：以普通用户视角在界面上验收系统行为。

本片建立前端工程与嵌入交付的完整链路，并交付只读的观察面板。配置编辑由下一片承载。

## 行为

### 工程布局

```
web/                        前端源码，独立工程
  src/api/schema.d.ts       由 api/openapi.yaml 生成，不手写
internal/webui/assets/      构建产物，提交进仓库
internal/webui/webui.go     //go:embed assets
```

`npm run build` 直接输出到 `internal/webui/assets/`，不经过中间拷贝步骤。

### 服务

- `muxio serve` 在同一端口同时提供 `/api/v1` 与面板。
- `/api/v1`、`/healthz`、`/readyz` 之外的路径交给面板；未知路径回落到 `index.html`，由前端路由处理。
- 面板资源以 `Cache-Control: no-cache` 提供：文件名已带内容哈希，而 `index.html` 必须每次校验，否则升级后仍加载旧资源。
- 面板不存在时（产物为空）返回明确提示而非空白页。

### 页面

**运行历史**：列出运行的 id、来源、状态、开始时间与三个计数。状态以颜色和文字同时表达，不单靠颜色。支持翻页，走 API 的游标分页。

**运行详情**：一次运行的全部字段与它的事件时间线，事件按时间正序、显示级别与消息。这是"哪一条为什么失败"的落点。

**设置**：只读展示当前生效配置，逐项标注来源（默认 / 文件 / 环境 / 命令行）。被环境变量覆盖的项必须显著标注，否则用户会以为文件里的值在生效。

### 类型与合同

- 客户端类型由 `openapi-typescript` 从 `api/openapi.yaml` 生成，不手写。
- 生成结果提交进仓库，门禁重新生成并比对，不一致即失败。

### 门禁

`selftest` 增加两项：

1. **嵌入产物存在且非空**。不需要 Node，任何环境都执行。
2. **产物与源码一致**。重新构建并比对；仅在 Node 与依赖可用时执行，跳过时必须明确说明跳过了什么，CI 始终执行。

第 2 项守卫 ADR-007 提到的新失败模式：源码改了而产物没重建，二进制里就是旧界面。

### 时间显示

API 返回 RFC3339 UTC。面板按本地时区显示，并在悬停时给出原始值——展示层负责时区转换，这是 data-model 的既有规则。

## 依赖

新增前端工具链，属于决策卡点第 1 条，已由维护者确认。基线对齐 conflow 但精简：

- 运行时：`react`、`react-dom`、`@base-ui/react`、`lucide-react`
- 构建与检查：`vite`、`typescript`、`@vitejs/plugin-react`、`tailwindcss`、`@tailwindcss/vite`
- 合同：`openapi-typescript`
- 测试：`@playwright/test`

不引入 `shadcn`（它把大量生成的组件源码塞进仓库）与 `@tanstack/react-table`（三个页面的表格用原生 `<table>` 足够，需要排序筛选时再评估）。

包管理器与 CI 缓存策略跟随 conflow 使用 npm。

## 边界与非目标

- 不实现配置编辑；本片的设置页只读。
- 不实现采集触发、搜索与导出。
- 不实现认证；服务仍只监听 loopback。
- 不实现主题切换、国际化与移动端适配。面板首期只服务维护者本人。
- 不引入前端状态管理库；三个页面的数据流用 `fetch` 与组件状态足够。

## 验收

- `muxio serve` 后浏览器打开监听地址即显示运行历史，无需任何额外进程。
- 运行历史与 `muxio runs` 的内容一致；点击一条运行可看到它的事件，与 `muxio runs show` 一致。
- 含失败行的运行，其详情页能看到每个被拒绝行的行号与原因。
- 设置页展示全部设置及其来源；设置 `MUXIO_LOG_LEVEL` 后该项显示为环境来源并有醒目标注。
- 分页在运行数超过一页时可完整翻完，无重复无遗漏。
- 未知前端路径回落到面板而非 404 JSON；未知 `/api/v1` 路径仍返回 404 JSON。
- `openapi-typescript` 重新生成的结果与仓库中一致。
- 前端源码改动后未重建产物时，`selftest` 报错并指出产物已过期。
- `go build` 在未安装 Node 的环境中成功，产出的二进制包含面板。
- Playwright 冒烟测试覆盖三个页面的主路径。
- `./scripts/selftest.sh` 全绿。
