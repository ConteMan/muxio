# Muxio Web

`web/` 是 Muxio 轻量 Monorepo 中的独立 Web 工程边界，承载 [Roadmap](../docs/roadmap.md) 的 M3 设置中心：观察运行与日志，管理配置。

当前仍未引入工具链。2026-08-10 的重排把 Web 从原 M5 提前到 M3，但提前的是顺序，不是前置条件——在 M2 的 `/api/v1` 覆盖运行、日志与配置之前引入 React、Vite 或 Node 依赖，只会得到一个没有数据可显示的空壳。

开始实现前必须满足：

1. Core 的 `/api/v1` 已覆盖运行历史、运行事件、失败详情和配置读写。
2. `api/openapi.yaml` 是唯一接口合同，并能生成客户端类型。
3. Web 独立构建、运行和发布；Go 构建不得依赖 Node。
4. Web 不得读取 SQLite、本地采集目录或承载采集业务规则。
5. 前端工具链与页面范围由独立 Spec 决定，并接入根 `selftest`。

界面形态参考桌面应用常见的设置中心：左侧分类导航，右侧表单与列表。承载的是 Muxio 自己的配置项与运行状态，不引入与采集无关的功能面。
